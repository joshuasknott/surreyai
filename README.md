# Surrey AI Hack 2027

A responsive landing page for a planned national UK student AI hackathon organised by Surrey Artificial Intelligence Society.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The current waitlist is an interactive front-end prototype. Connect the form to the chosen mailing-list or database provider before collecting real registrations.

## Design direction

Surrey AI Hack has a standalone editorial identity built around warm paper, deep forest green, icy sky blue, vermilion red and commissioned-feeling documentary photography. The society identity is deliberately limited to organiser credits in the header and footer.
